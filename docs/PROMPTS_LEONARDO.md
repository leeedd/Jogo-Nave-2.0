# Metal Space: TUDO que falta, para o Leonardo.ai

## Como usar no Leonardo
- Modelo: **Leonardo Phoenix** (ou Flux), Style **Pixel Art** se aparecer.
- **Number of images: 1.** Aspect ratio: o indicado em cada item (use o mais próximo que existir).
- Prompts em inglês: o Leonardo entende melhor assim.
- Cole sempre o **Negative prompt** abaixo no campo Negative Prompt.
- Uma geração por item. Se repetir, mude o Seed (ou deixe aleatório).
- Baixe cada imagem com o nome de arquivo indicado e me mande tudo num zip.

**Negative prompt (use em todos):**
```
text, letters, words, watermark, logo, signature, frame, border, multiple characters, collage, grid, cropped, cut off, blurry, 3d render, realistic photo, gradient background
```
